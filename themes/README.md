# Ready themes

Themes that come with KDE Theme Manager. The installer adds each one unless you
already have a theme with that name (nothing is applied or overwritten);
`install-theme-profile-kit.sh --no-themes` skips them. By hand:

```bash
theme-profile import themes/glass        # then: theme-profile apply glass
```

Each folder is a public export (`theme-profile export NAME --dir=themes/NAME --public`):
only the look (see `docs/THEMES.md`), the home folder written as `$HOME`, no desktop
icon positions, no Look & Feel preview screenshots. Assets that may not be
redistributed are **not** included — they are *dependencies* with their official
source; after importing, KDE Theme Manager's *This Theme Needs* dialog (or
`theme-profile deps NAME --install`) fetches them. System packages are only
shown as commands.

The code of this repository is MIT; every asset below keeps its own licence. The
other files are configuration written for these themes (colours, fonts, CSS,
effect settings); the oh-my-posh prompt is oh-my-posh's own `aliens` theme (MIT,
https://github.com/JanDeDobbeleer/oh-my-posh).

## Adding a theme

1. Make the look you want and save it: `theme-profile save NAME --description=…`.
2. Mark what you may redistribute (your wallpaper, your Look & Feel…):
   `theme-profile license NAME ASSET --license=SPDX --source=URL` (`kind:name` when two
   assets share a name). Anything unmarked stays out and becomes a dependency.
3. `theme-profile export NAME --dir=themes/NAME --public`, check the folder, open a PR.
