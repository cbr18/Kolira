## Настоящая Plasma в изоляции

`tests/e2e/schedule-history.py`: Docker без сети, отдельные HOME/XDG, D-Bus,
процессы и Wayland display. Системные `/usr` и `/etc/fonts` подключены read-only;
конфиги и сокеты рабочего стола хоста не подключались. Это не чистая установка
на другой машине. Сборка образа с загрузкой Plasma через зеркала Arch не удалась
из-за timeout/reset загрузок; использован установленный системный runtime.

```json
{
  "ok": true,
  "scheduled_operation": "apply-kM9RX8",
  "restore_operation": "apply-32LT5x",
  "live_hooks_disabled": false,
  "gui_window_running": false,
  "cli_sha256": "77e094e3d96b4ce99c81c6e2720e5553c225dbf4b98879e6db0f818efa5e495c",
  "kwin_version": "kwin 6.8.2"
}
```

Проверено: настоящий KWin/plasmashell, применение по следующему времени при
закрытом GUI, источник `schedule`, связь с бэкапом, персональный ключ,
восстановление до исходных байтов с новым ID/страховочной копией. После
восстановления оба сервиса доступны. Hooks не отключались; только timeout
внешних команд ограничен 15 секундами для теста.

В логе есть предупреждения порталов и сбой ActivityManager. Эти службы не
являлись предметом smoke-теста. Не проверялись визуальная идентичность,
реальный suspend/resume, повторный вход через display manager и весь набор
приложений пользователя; расчёт времени/повторы проверяются отдельно.

## Загрузка инструкций клиентами

Воспроизводимый `tests/e2e/agent-discovery.py` использует временные профили и
локальный HTTP-приёмник, который намеренно возвращает 400. Модель не запускается,
внешний API и реальные ключи не используются. Исследуется фактически
сформированный загрузчиком запрос, а не вывод модели по её памяти.

- Codex CLI 0.167.0: текст включён из корня; из вложенной темы — при явном
  `project_root_markers=[".git","AGENTS.md"]`. Обычный вложенный запуск в чистом
  профиле не включил родительский текст.
- Claude Code 2.1.316: корневой `CLAUDE.md` подключает канонический текст.
  Вложенный запуск, включая попытку дополнительного каталога, в проверке
  не включил текст; документирован запуск из корня `themes/`.
- Ненулевой exit клиентов ожидаем из-за тестового ответа 400; это не реальная
  AI-сессия и не оценка качества/послушания произвольной модели.

Сценарий подготовки темы выполняется через настоящие MCP/Rust операции в
`test_mcp_workflow.py`; применение/восстановление с внешними hooks подтверждены
отдельной Plasma-проверкой выше. [Запуск и ограничения](../MCP.md).
