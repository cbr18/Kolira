# Меньше копий: ссылки вместо копий там, где ресурс воспроизводим

Status: TODO

## Проблема

Сейчас приложение копирует ресурсы в нескольких местах (2026-11-04):

| Что копируется | Куда | Когда |
|---|---|---|
| Активная **пользовательская** тема Kvantum (`~/.config/Kvantum/<theme>`) | в снимок профиля | при каждом `save` (если трекается `kvantum`) |
| `ThemeProfile<Имя>` (перекраска базовой темы Kvantum) | `~/.config/Kvantum/` | `palette apply --targets=kvantum` |
| `Sandstone` (захардкожено в компоненте `kvantum`) | в снимок профиля | при каждом `save` |
| Обои | `<профиль>/wallpaper/` | при каждом `save` (если трекается `plasma_shell`) |
| Весь `~/.local/share/color-schemes` | в снимок профиля | при каждом `save` |
| «Создать тему…» (Python) | `$XDG_DATA_HOME/Kvantum/<имя>` — **Kvantum, вероятно, ищет только `~/.config/Kvantum` и `/usr/share/Kvantum`**, проверить | по кнопке |

Системные темы Kvantum (`/usr/share/Kvantum/*`) и любые уже установленные темы
**не копируются** при выборе через компонент «Тема Kvantum» — копия появляется
только у пользовательской темы в снимке профиля и при генерации из палитры.

## Что сделать

- [ ] Сгенерированные ресурсы (`ThemeProfile*` для KDE/Kvantum) хранить в профиле
      как рецепт (`palette.json` + имя базовой темы Kvantum + версия генератора) и
      пересобирать при `apply`, если каталог отсутствует; копию держать только
      как fallback (или по флагу).
- [ ] Пользовательскую тему Kvantum копировать в снимок только если её нет в
      системных путях; по хешу содержимого не дублировать между профилями
      (общее хранилище `theme-profile/assets/<sha256>/` + ссылка в манифесте).
- [ ] То же для обоев и цветовых схем: content-addressed хранилище вместо
      копии в каждом профиле и каждом pre-save бэкапе.
- [ ] Убрать захардкоженный `Sandstone` из компонента `kvantum` (Rust и Python).
- [ ] Проверить, читает ли Kvantum `$XDG_DATA_HOME/Kvantum`; если нет —
      `create_custom_theme` должен писать в `~/.config/Kvantum`.
- [ ] Миграция: старые профили с копиями продолжают работать.
- [ ] Документация: `docs/CURRENT_APP.md`, `docs/PALETTE.md`, `docs/ROLLBACK.md`.

## Не входит

- Удаление уже созданных копий у пользователя без его подтверждения.
