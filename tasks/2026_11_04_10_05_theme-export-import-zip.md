# Экспорт / импорт тем в .zip

Status: DONE (2026-11-04; формат и проверки — docs/THEMES.md «Export and import»)

Связано: [publish-repo-with-themes](2026_11_04_10_10_publish-repo-with-themes.md) —
формат архива = формат темы в репозитории.

## Проблема

Профиль — это снимок десятков личных конфигов с абсолютными путями
(`/home/cbr/...`), его нельзя просто передать другому человеку или на другую
машину. Нужен переносимый пакет темы.

## Формат `.ktmtheme.zip` (предложение, утвердить)

```
manifest.json        # schema, name, description, author, license, app/generator versions,
                     # список компонентов, sha256 файлов
palette.json         # base16 + accent (если тема из палитры)
bundle.json          # theme-bundle без абсолютных путей: ссылки на темы по имени,
                     # параметры (углы, blur, прозрачность), темы приложений (id из магазинов)
assets/
  color-schemes/*.colors
  kvantum/<theme>/*  # только если лицензия позволяет; иначе рецепт (база + палитра)
  wallpaper/<file>   # опционально, с указанием лицензии/источника
  look-and-feel/<pkg>/
configs/             # ОПЦИОНАЛЬНО (--with-configs): санитизированные снимки
                     # (без путей $HOME, ключей, токенов, истории)
```

## Решения (2026-11-04)

- **Тема и есть пакет** (темы = «снимки»; см.
  `2026_11_04_10_00_asset-copies-by-reference.md`). Сохранение, применение,
  экспорт/импорт и темы в репо — один формат; текущие профили-снимки
  мигрируют в пакеты.
- Тема — полный снимок файлов оформления (включая панели и правила окон) +
  `theme.json` (`docs/THEMES.md`; решение «только ключи» отменено 2026-11-04).
  Поэтому экспорт **обязан санитизировать** личное: пути `$HOME`, иконки и
  ярлыки рабочего стола в appletsrc, историю/недавние файлы, секреты.
- **Зависимости в манифесте**: у каждого внешнего ресурса — тип, имя и «где взять»
  (URL KDE Store / пакет AUR / id в магазине Zed/Open VSX / id галереи).
- **Отчёт о недостающем** при импорте и в `validate`: «не хватает: …, где взять: …»;
  недостающее пропускается, остальное применяется; где источник известен
  приложению (магазины Zed/Cursor, галерея палитр) — кнопка «Установить».
- **Лицензии ресурсов**: у каждого ресурса внутри пакета — лицензия и источник;
  то, что нельзя распространять, — только ссылкой.

## Что сделать

- [ ] Rust: `kolira export NAME --out=FILE [--with-configs] [--no-wallpaper]`
      и `kolira import FILE [--name=NEW] [--apply]`; логика в Rust (crate `zip`).
- [ ] Санитайзер: `$HOME` → `${HOME}`, удаление секретов (ключи с
      `token|key|secret|password`, `zed` `language_models`, история, recent files),
      отказ экспортировать неизвестные бинарные файлы.
- [ ] Импорт безопасен: защита от zip-slip, валидация имени профиля, лимиты
      размера/числа файлов, проверка sha256, только известные пути назначения,
      бэкап перед перезаписью, конфликт имён → вопрос/`--name`.
- [ ] Отсутствующие зависимости при импорте (тема Kvantum/иконки/шрифт не
      установлены) — список в отчёте `validate`, тема применяется частично.
- [ ] GUI: «Экспорт…» в меню «Другие действия» карточки профиля, «Импорт темы…»
      рядом с «Сохранить текущее…»; диалоги файлов; отчёт об импорте.
- [ ] MCP: `export_theme`, `import_theme`.
- [ ] Тесты: round-trip export→import на временном HOME, zip-slip, битый архив,
      секрет не попадает в архив.
- [ ] Документация: README, `docs/CURRENT_APP.md`, `docs/MCP.md`, новый раздел формата.

## Итог (2026-11-04)

- Rust `src/share.rs`: `kolira export NAME [--out=FILE.zip|--dir=DIR]
  [--no-wallpaper]`, `kolira import FILE.zip|DIR [--name] [--force]
  [--apply] [--json]`; crates `zip` (deflate), `sha2`.
- Санитайзер свёлся к трём правилам: домашняя папка → `$HOME`, без положений
  значков рабочего стола, без `user=` в manifest.txt. Секретов в отслеживаемых
  файлах нет; личные нерелевантные файлы (QtProject.conf, obsidian.json,
  Preferences) больше не отслеживаются вовсе. Из «библиотечных» папок
  (color-schemes, Kvantum, look-and-feel…) — только ресурсы темы.
- Импорт: zip-slip, симлинки, SHA-256, лимиты, временная папка + rename,
  конфликт имён → `--name`/`--force` (бэкап `pre-import-*`), отчёт `missing`.
- GUI (Экспорт… / Импорт темы… / диалог конфликта / недостающие части), MCP
  (`export_theme`, `import_theme`), тесты (Rust 4, bash 10, pytest 1).
