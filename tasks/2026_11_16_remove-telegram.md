# Удаление поддержки мессенджеров с ручным выбором темы

Статус: IN PROGRESS — 2026-11-16.

Запрос пользователя: перезапуск приложения после Apply допустим. Telegram убрать
из поддержки полностью; тот же адаптер Kotatogram удаляется вместе с ним.
Личные клиенты, аккаунты, чаты и выбранные темы не сбрасываются.

## Изменения

- Удалён Rust-модуль генерации/загрузки базы палитры и все вызовы из palette Apply,
  defaults, staged app sync, actions, реестра приложений и CLI-подсказок.
- Удалены GUI-adapter и его data descriptor, пункты списков/действий, переводы,
  MCP-подсказки и инструкции настройки. Реестр теперь содержит 51 приложение.
- Все восемь комплектных тем очищены от двух targets и palette-файлов; manifest и
  export hashes обновлены. Теперь в комплектных темах по 33 app_targets.
- Maintenance example больше не принимает внешнюю базовую палитру, ничего для
  удалённых клиентов не генерирует и удаляет их устаревшие targets/manifest rows.
- Совместимость со старыми пакетами ограничена пропуском retired targets и путей.
  Их конфиги, data и Flatpak-контейнеры не захватываются, не применяются и не
  экспортируются. Обычный before/after и старые created/replaced undo-журналы
  пропускают эти файлы, даже если совпадает старый hash. Это защитный запрет,
  а не оставшаяся поддержка. Исторические резервные копии не удаляются.
- Очередь уточнена: обычный перезапуск отмечается в P0 и не является причиной
  для P4; туда относятся выбор/импорт/сброс/дополнительная настройка и пробелы
  проверки. Сессии автоматически не завершаются.

## Проверка

Регрессия: старая тема с retired targets и ресурсами + три формата старого
undo-журнала → preview/Apply/возврат в трёх переходах сохраняют личные данные.
Прежняя CLI-цель больше не принимается; GUI-adapter отсутствует.
Проверки всех восьми тем проверяют импорт/экспорт, палитры и возврат без этих
ресурсов. Реестр и Python-adapters не содержат удалённые приложения. Старый
checksummed export импортируется без ресурсов клиентов; новый export не содержит
retired targets. Проверены все три прежних формата undo-журнала.

Общие проверки: **275 Rust**, **345 Python/Qt**, **260 shell** PASS; clippy
`--all-targets -- -D warnings`, shellcheck, cargo fmt и Python syntax PASS.
Переводы: 918 finished, 0 unfinished, obsolete строки удалённых клиентов удалены.
Контрольные суммы всех восьми комплектов сходятся; в каждом 33 app_targets.
BreezeLight/BreezeDark и акцент от обоев только для Glass/Material You сохранены.
Итоговая release-сборка завершается.

Live deploy/Apply не выполнялись, данные установленных клиентов не удалялись.
