# Довести Minecraft Overworld Dark

Статус: DONE (реализация и изолированный цикл), 2026-11-09.
Реальный Desktop Apply и установка внешних пакетов не выполнялись.

## Реализация

- Значения `theme.json` прочитаны Rust `field get` из снимка и совпадают
  с конечными файлами; конфиги эффектов, декорации и стиля больше не противоречат им.
- Оригинальные Kvantum SVG-части (1103 именованных элемента), квадратные
  кнопки с фасками, каменные/дубовые детали, непрозрачные окна без blur/анимаций.
- 16 SVG-иконок с корректным index.theme и наследованием breeze/hicolor.
- Исправлены форматы Zed, btop, Konsole, yazi, cava, wofi и GTK CSS;
  VS Code/Cursor используют встроенную тему и локальные цвета вместо чужого UUID.
- Новые AI-generated voxel-обои вместо фотографии; происхождение/MIT описаны
  в LICENSE. Fastfetch, поведенческие настройки и неиспользуемые файлы исключены.
- Пакет теперь содержит export.json: 53 файла с SHA-256, все пути существуют.
- Внешние зависимости: Kvantum, Klassy, Monocraft. Для Monocraft AUR RPC
  подтвердил `otf-monocraft`; прежнего `ttf-monocraft` там нет.
- Rust сохраняет/проверяет/переносит встроенные icons assets с защитой путей
  и симлинков. Приватные иконки при public export становятся зависимостями;
  тесты источников KNewStuff/installed-assets проверяют этот путь.
- Экспорт сохраняет LICENSE и профиль Konsole из снимка независимо от
  профиля экспортирующей машины. Добавлены регрессии. Проверка предпросмотра
  обновлена для семи комплектных тем.

## Проверка и пределы

- Release build, Clippy `--all-targets -D warnings`, rustfmt, shellcheck и
  `git diff --check` прошли.
- Полный финальный offscreen Python/Qt: 336 passed.
- 198 Rust-тестов прошли при явном исключении одного теста восстановления;
  все семь комплектных тем импортируются/применяются, SHA-256 предпросмотра
  совпадают с применёнными файлами. Регрессии icons/симлинков/экспорта проходят.
- Полный Rust-прогон выявил сбой
  `interrupted_record_survives_history_pruning_until_explicit_recovery`:
  ожидает блокировку по прерванной операции, но параллельные правки
  `operation.rs` разрешают новую операцию. Эти правки в рамках темы не менялись.
- Shell/installer: 256 passed, 2 failed. Оба оставшихся сбоя — сценарии
  отсутствующего Kvantum/зависшего инструмента, ожидающие обязательный systemd
  start/recovery diagnostics при параллельно изменённом восстановлении Plasma.
  Пять сбоев старых ожиданий иконок устранены обновлением тестов нового контракта.
- Схемы Zed/Yazi с официальных сайтов проходят jsonschema; GTK 3/4 CSS
  проверены реальными CssProvider без ошибок. Qt/Kvantum отрисован offscreen,
  SVG распознаётся, иконки находятся; Monocraft в окружении отсутствует,
  его установка не имитировалась и не объявляется проверенной.
- Публичные directory/ZIP export, import и apply с `KTM_THEME_NO_APPLY=1`
  прошли на временном HOME/XDG: нет missing resources/errors, сохраняются
  размер шрифта KDE/Konsole, команда оболочки Konsole, комментарии JSONC,
  размер шрифта редактора, виртуальные рабочие столы, масштаб и fastfetch.
- Отдельно проверены отсутствие пропущенных/неучтённых файлов, SHA-256,
  соответствие метаданных Rust-полям и существование путей компонентов.
