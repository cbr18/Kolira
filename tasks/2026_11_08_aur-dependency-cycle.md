# Реальный цикл зависимостей из AUR

**Статус:** TODO (2026-11-08). Заведено по запросу пользователя.

Продолжение проверки [управления зависимостями](2026_11_07_dependency-management.md):
цикл обычного пакета через pacman проверен, реальная сборка из AUR пока не выполнялась.

## Требования

1. В чистом изолированном Arch Linux окружении с обычным пользователем и
   поддерживаемым AUR helper выполнить реальную загрузку, сборку и установку
   зависимости темы. Записать пакет, версии окружения/helper и журнал операций.
2. Проверить цикл через менеджер: установить → проверить пакет, ресурс и реестр
   → удалить → подтвердить отсутствие → переустановить. Повторная установка
   не создаёт дубликатов и не присваивает владение существовавшему ранее пакету.
3. Проверить общий пакет двух тем, предупреждение о затронутых темах, уже
   установленный внешний пакет и восстановление состояния после частичного сбоя.
4. Проверить ошибку загрузки/сборки, отсутствие helper, ожидание ввода/пароля,
   отмену и повторную попытку. GUI остаётся отзывчивым, ошибки видны; выполняющаяся
   привилегированная транзакция завершается безопасно.
5. Проверить учёт источника `aur`, доступность установленного ресурса и политики
   `ask/always/never` для системных пакетов. Исправления выполнять в существующем
   Rust-исполнителе и реестре; Python остаётся адаптером GUI.

## Приёмка

- [ ] Полный реальный цикл AUR выполнен в изоляции, журналы и результаты записаны.
- [ ] Установка подтверждается фактическим пакетом/ресурсом, удаление — их отсутствием.
- [ ] Общие и внешние зависимости обрабатываются корректно, дубликатов нет.
- [ ] Ошибки, ожидание пользователя, отмена и повтор не блокируют GUI навсегда.
- [ ] Найденные дефекты исправлены и покрыты подходящими регрессионными тестами.
- [ ] Обновлены `docs/DEPENDENCIES.md`, карточка и индекс задач; при изменении
      поведения также обновлены пользовательская документация и changelog.

Пакеты проверять в одноразовом контейнере/VM. Подставные команды и нулевой
exit code без проверки установки не считаются выполненным реальным циклом.
