## Как сделать (выбрать при старте)

- Ядро отдаёт **ключи** (`id` действия/пункта, коды сообщений с параметрами),
  а тексты живут в GUI под `qsTr`/`tr` → один каталог переводов
  (`i18n/*.ts`), lupdate их видит. Предпочтительно: CLI остаётся английским
  для скриптов, GUI переводит по id.
- Альтернатива: локализация в Rust по `LANG` (gettext/fluent) — второй
  каталог, хуже.
- Поля инспектора: генерировать `QT_TRANSLATE_NOOP` из `theme_fields.json`
  (скриптом в `update-translations.sh`) или читать перевод по `id`.
- Проверка: тест, что у каждого `id` автоматизации/действия/поля есть перевод;
  `update-translations.sh` → 0 незавершённых.
