# Не трогать fastfetch и меню запуска

**Статус:** DONE (2026-11-07).

## Требование пользователя

Темы и установка приложения не должны менять fastfetch и существующее меню
запуска. Другому человеку не требуется скачивать Simple Application Launcher.
Это отдельная задача от управления зависимостями.

## Исходное состояние до исправления

- **Fastfetch ещё затрагивается:** `tracked_apps.rs` содержит компонент `fastfetch`
  с `active_assets::fastfetch()` (конфиг и логотип), готовые темы перечисляют
  `.config/fastfetch/config.jsonc` в `manifest.txt`; `theme.rs` упаковывает логотип.
  Значит требование «не трогать fastfetch» ещё не выполнено.
- **Simple Application Launcher уже исключён:** готовые темы и QML не требуют его;
  `tests/test-scripts.sh` содержит проверку отсутствия `simplekickoff` и
  `Simple Application Launcher`. При этой проверке документации тест не запускался.
- **Внешность меню ещё меняется:** `layout.rs` сохраняет раскладку, но
  `LAUNCHER_LOOK` содержит `icon`, `useCustomButtonImage`, `customButtonImage`.
  Значок/изображение кнопки существующего меню могут переноситься из темы.

## Критерии приёмки

- [x] Fastfetch исключён из тематизации: save/apply/new/import/export и старые темы
  не перезаписывают и не удаляют его конфиг/логотип, не устанавливают fastfetch.
- [x] Тема не заменяет существующее меню, не меняет его настройки, значок или
  изображение кнопки; не добавляет зависимость от другого launcher.
- [x] Готовые темы и QML не требуют Simple Application Launcher.
- [x] Регрессионная проверка: собственные fastfetch и меню → несколько тем → возврат;
  файлы/настройки сохраняются без изменений. Старые темы не возвращают это поведение.
- [x] Документация и готовые темы согласованы с новым контрактом.

Правки логики — Rust core; миграция должна сохранять пользовательские данные.
Ранее зафиксированные изменения fastfetch при возврате считаются историей,
новое требование — вообще не тематизировать его.

## Реализация

Fastfetch удалён из Rust/Python реестров и готовых тем. Rust фильтрует старые
assets/dependencies, пути при save/apply/export/import и записи прежнего журнала
отката. Старые темы продолжают читаться, но fastfetch не восстанавливают и не удаляют.
В `layout.rs` launcher исключён из оформляемых виджетов: его плагин, настройки,
значок и изображение кнопки остаются пользовательскими; зависимости не создаются.
Контрольные суммы готовых тем пересчитаны.

## Проверка

- Rust: 121 тест, включая сохранение значка, customButtonImage и избранного для
  kickoff/kicker/kickerdash/simplekickoff при применении старой темы.
- Python (offscreen): 276 тестов; одно существующее предупреждение pytest-qt о QCoreApplication.
- `cargo clippy --all-targets -- -D warnings`, `shellcheck tests/test-scripts.sh` и `git diff --check` — без ошибок.
- Контрольные суммы всех файлов шести готовых тем проверены.
- CLI-регрессии проверяют save/apply/export/import, возврат и прежний журнал,
  который раньше мог восстановить или удалить файлы fastfetch.
- Общий CLI/installer-прогон: 252 проверки прошли, два старых ожидания тестов
  потребовали обновления (перенос значка меню и поиск имени launcher в README).
  После исправления эти сценарии перепроверены отдельным прогоном.
- Живое оформление пользователя при проверке не переключалось; установленные
  копии приложения не обновлялись.
