# Предварительный diff перед применением темы

**Статус:** DONE (2026-11-08). Просмотр подключён к GUI, CLI и MCP. Реальная Plasma-сессия проверена визуально; фактическое переключение темы не выполнялось.

## Требования

1. До применения показать изменения относительно текущего живого оформления:
   изменяемые параметры, сбросы/удаления, сохраняемые пользовательские настройки,
   недостающие зависимости и необходимые перезапуски приложений.
2. Рассчитывать предварительные изменения теми же Rust-политиками, которые
   использует apply, включая фильтры старых тем и сохранение обоев. Учесть
   восстановление изменений предыдущей темы из журнала.
3. Дать возможность сохранить текущее оформление как тему перед продолжением.
   Отмена просмотра не меняет живые конфиги и не запускает установку зависимостей.
4. Связать подтверждение с проверенным состоянием: если тема или живые настройки
   изменились, пересчитать diff перед записью. Использовать
   [защиту применения](2026_11_08_apply-protection.md).
5. Рассчитывать diff асинхронно; UI остаётся отзывчивым. Сверить существующий
   диалог сравнения и переиспользовать подходящие элементы.

## Приёмка

- [x] Diff соответствует фактическому результату apply для шести комплектных тем, старых снимков и сохранённой копии обоев; SHA-256 файлов совпадают.
- [x] Показаны зависимости, сбросы, фактические перезапуски и сохраняемые личные настройки.
- [x] Сохранение текущего оформления, отмена, очередь запросов и повторное подтверждение устаревшего diff проверены.
- [x] Добавлены Rust/Python/MCP проверки; обновлены документация, переводы, changelog, roadmap и очередь.

## Проверка

- Cargo release build, 176 Rust-тестов и Clippy без предупреждений; 319 Python/Qt-тестов, 256 shell-проверок, shellcheck, qmllint и генерация 763 русских переводов.
- Диалог открыт в настоящем Plasma окне с временным HOME: проверены русский текст, раскрытие diff, закрытие и отсутствие Apply.
- `KTM_THEME_NO_APPLY=1`: Apply проверялся только в изолированном HOME; применение к пользовательской сессии здесь не запускалось.
- Установлено штатным установщиком с резервной копией CLI/GUI; темы пользователя не синхронизировались.
- Дифф ограничен 1 MiB текста/1500 строк на файл; вычисляемые Plasma и внешними утилитами кэши не прогнозируются. Подробности: [контракт](../docs/APPLY_PREVIEW.md).
