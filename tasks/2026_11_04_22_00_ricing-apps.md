# Приложения, которые тематизируют в популярных дотфайлах

Status: DONE (2026-11-04) — проверено харнессом (разделы 19–24) и вживую (Neovim headless)
Связано: [appearance-only-and-dependencies](2026_11_04_20_30_appearance-only-and-dependencies.md)

## Источник

Исследование 2026-11-04: состав HyDE, end-4/dots-hyprland, JaKooLit, ML4W,
шаблоны matugen-themes, звёзды портов Catppuccin. Приоритет — приложения,
для которых сообщества делают общие темы, с учётом KDE-сессии и того, что
стоит у пользователя.

## Принципы (как уже сделано для kitty/Alacritty)

- Тема хранит **только оформление**; размеры шрифтов/курсора не переносятся.
- Где можно — отдельный файл темы, подключаемый из личного конфига
  (`include`/`require`/`config-file`/`@import`); иначе — слияние ключей.
- Палитра генерирует файлы для приложения (как matugen), чтобы «тема из обоев»
  красила и его.
- Темы/аддоны из магазинов — зависимости с официальным источником.
- Системные вещи (SDDM, GRUB, Plymouth) — без sudo из приложения: зависимость
  + команда.

## План

### A. Инфраструктура
- [x] Профили со случайным именем (Zen, Firefox): в теме под своим именем, у
      получателя — в его активный профиль (сейчас Zen чужой темы молча
      пропускается).
- [x] Динамические пути (активный профиль Konsole).

### B. Приложения
- [x] **Konsole**: цветовая схема `.colorscheme` (целиком; палитра → генерация),
      профиль — только `[Appearance]` (схема, семейство шрифта).
- [x] **Neovim**: `lua/kolira.lua` (`colorscheme`, прозрачность),
      подключается из `init.lua`; палитра → `colors/kolira.lua`
      (base16 → группы подсветки, без плагинов).
- [x] **Firefox**: `chrome/userChrome.css`/`userContent.css` целиком,
      `user.js` — только префы оформления; тема-аддон → зависимость (AMO).
- [x] **Discord (Vesktop/Vencord)**: CSS-темы + `enabledThemes`; палитра → CSS.
- [x] **Spotify (Spicetify)**: `config-xpui.ini` `[Setting] current_theme/color_scheme`
      + папка темы; после применения `spicetify apply`; палитра → `color.ini`.
- [x] **SDDM**: тема — зависимость (пакет/KDE Store), выбор темы — команда
      (`/etc` требует root).
- [x] Дёшево и популярно: fish `fish_color_*`, oh-my-posh (файл темы промпта),
      cava `[color]`, ghostty (`config-file` с темой), yazi `theme.toml`,
      bat (`--theme`). lazygit — пропущен (тема вложена в YAML).

### C. Проверка
- Для каждого приложения: сохранить → чужие значения → применить → оформление
  на месте, личное не тронуто; экспорт/импорт на другом HOME.
