Область: восемь коммитов b6596af..aa45e73 в explore/two-stage-apply.
Существовавшие незакоммиченные правки старых Apply-popup сохранены отдельно
в git stash; в коммит ревью не включаются и возвращаются после слияния.

## Исправлено

- Восстановлена проверка симлинков назначения; пути и содержимое редакторского
  кэша проверяются до записи. VSIX сохраняет вложенные имена и ограничен размером.
- Кэш устанавливается как полное расширение в отдельном namespace; VSCodium
  использует .vscode-oss. Исходные расширения не удаляются. Манифест устанавливает
  только темы, без исполняемых точек входа/посторонних contributions. Копирование
  расширения на себя больше не обнуляет файлы. ZIP переносит кэш; public его исключает.
- Оба этапа — одна Rust-транзакция: preview, подтверждение, блокировка, резервная
  копия, откат и журнал возврата. Второй этап выполняется после рестарта Plasma.
- Генерация приложений — явный app_targets[], по умолчанию пустой. Явные ресурсы
  снимка имеют приоритет. Старые темы с палитрой не включают все приложения.
- Firefox использует отдельный импортируемый CSS и user.js; личные CSS/privacy
  сохраняются. Chromium Preferences исключён из записи и снимков: старый код
  заменял целиком profile и не имел проверенного контракта тематизации.
- Обычные save/preview/apply не скачивают расширения; подготовка кэша — только
  через явный --install-missing. --without-dependencies подавляет такую подготовку.
- Исправлены TypeError Apply changes, переопределённый слот KCM и Qt-сигнатура
  saveProfile. Галочка пропуска follow-up перенесена в настоящий Apply preview,
  её значение входит в token и сохраняется при пересчёте/подтверждении.
- Сохранение палитры требует применения к KDE; Rust повторно проверяет палитру,
  активную схему и живые цвета под блокировкой. Существующая тема не затирается.
- Исправлены старые checksum manifest.json/theme.json Minecraft и устаревшая
  ссылка теста на удалённый bash-конвейер переводов. Конвейер перенесён в Python;
  shell-мок systemctl теперь отражает остановку/запуск службы вместо вечного active.

## Границы

Chromium намеренно отложен. Автоматический capture редакторов охватывает VS Code
и Cursor; VSCodium/Windsurf/Zed поддерживают явные локальные метаданные. Исходные
пункты --vscode-theme и отдельный GUI выбора источника из старой карточки не
реализованы. Reload установленной темы зависит от редактора/версии; запуск всех
реальных редакторов в этой задаче не заявляется. Telegram follow-up использует
только ранее загруженную базовую палитру. Полная визуальная матрица UI и AUR
не подменяются этими проверками.
