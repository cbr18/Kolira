## Проблема

При создании темы Everforest (2026-11-04) выяснилось, что приложение не умеет
создать тему само: нет палитры, «Создать тему…» только копирует текущую схему,
Kvantum не перекрашивается, тем для редакторов нет и поставить их нельзя, новая
тема наследует эффекты glass, L&F остаётся `glass`, профиль «замораживает»
случайные темы приложений. Из 22 найденных проблем 10 исправлены сразу,
12 остаются — эта задача закрывает их (кроме загрузки тем KDE/GTK/иконок из
интернета).

## Решения (согласованы с пользователем 2026-11-04)

- Порядок: **P0 → задача про обои → P1 → P2 → P3**, ветка на фазу.
- Логика палитры и генераторов — **Rust** (`palette.rs`, `theme-profile palette …`).
- Формат палитры — **base16 + отдельный акцент**.
- Источники: галерея base16 (tinted-theming, по запросу + кэш + встроенный
  офлайн-набор), импорт файла, ручная правка, «из обоев» (GUI —
  `Kirigami.ImageColors`, CLI/MCP — свой алгоритм в Rust).
- Генераторы v1: цветовая схема KDE (все группы, `[WM]`, состояния), kitty, Alacritty.
- Kvantum: свой шаблон с метками для сгенерированных тем + выбор любой
  установленной темы Kvantum.
- Zed / Cursor / VS Code: поиск в магазине и установка (Cursor/VS Code — их CLI
  `--install-extension`; Zed — архив из `api.zed.dev` → `~/.config/zed/themes`).
- btop: выбор из установленных с подсказкой по имени.
- Определение приложений — по бинарнику; «только конфиг» = не установлено.
- Новая тема: «Начать с…» (профиль или нейтральный шаблон) + живая правка.
- Свой пакет Look & Feel на профиль, только `defaults`.
- В профиль — только выбранные/установленные/сгенерированные темы приложений.
- P0: внятная ошибка сокета + запуск без single-instance; установщик
  предупреждает, `--restart` перезапускает.
- P3: макет окна и терминала в редакторе палитры с проверкой контраста.
- Старые профили не трогаем; приёмка — пересоздать Everforest новым путём.

### Допущения (подтверждены)

1. Палитра доступна агентам через MCP.
2. Генераторы поддерживают светлые base16-схемы.
3. Нейтральный шаблон: без размытия, непрозрачность 100, Breeze, без своего L&F.
4. Сетевые функции отключаются в настройках.

## Не входит в задачу

- Загрузка тем KDE/GTK/Kvantum/иконок из интернета (KNewStuff) — п.4 для системы.
- Генераторы тем Zed/VS Code из палитры (берём темы из магазинов).
- Черновик темы без применения к системе (модель остаётся «живой»).
- Конвертация старых профилей в палитру.
- Раскладка панелей в L&F.

## Критерии приёмки

- Everforest пересоздаётся без ручных скриптов: галерея base16 → генераторы →
  Kvantum-шаблон → L&F `theme-profile-everforest` → тема Zed/Cursor из магазина
  → «Сохранить как профиль»; `validate_profile` проходит; `apply glass` →
  `apply everforest` возвращает ту же картину.
- Новая тема от «нейтрального шаблона» не содержит эффектов glass.
- Профиль не содержит тем приложений, которых пользователь не выбирал.
- Все проверки из AGENTS.md зелёные; документация обновлена в той же фазе.
