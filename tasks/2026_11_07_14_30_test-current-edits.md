# Проверка текущих правок на чистой машине

**Статус:** CLOSED без прогона (решение пользователя, 2026-11-07): на чистой машине эти правки не проверялись, образ Docker удалён. Проверено только тестами `tests/test-scripts.sh` и импортом тем.

## Что проверить

Правки, которых ещё не было в прогоне с настоящей Plasma:

- SDDM убран из приложения;
- `my-original-look` при первой установке;
- тема без обоев и `--keep-wallpaper` оставляют обои любого вида.

## Как

`tests/e2e/friend-in-container.sh` в образе `tests/e2e/Dockerfile` (две домашние папки:
после первого запуска Plasma и настроенная, `E2E_POPULATED=1`). В контейнере GitHub может
быть недоступен: склонировать на хосте и передать клон.

Для обоев добавить в сценарий: тема без обоев при «картинке дня» и слайд-шоу. Для
`my-original-look`: возврат именно к ней, запуск установщика уже в живой сессии.
