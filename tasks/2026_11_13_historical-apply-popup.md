# Старые прерванные применения без всплывающей ошибки

Статус: DONE — 2026-11-13 (реализация; проверка и установка указаны ниже).

## Причина и изменение

`ProfileController.refresh()` выдавал сохранённые незавершённые операции через
`operationFinished(False, ...)`. Множество уже показанных ID жило только в памяти:
при каждом новом запуске GUI ошибка `apply-AnHD2S` показывалась снова.
Эта запись относится к сбою запуска plasmashell 2026-11-09; повторное
восстановление 2026-11-10 зафиксировало конфликты с последующими изменениями.

Загрузка профилей больше не запрашивает незавершённые операции и не выдаёт их
как новые ошибки. Их читает существующая «История смен тем»: ID, состояние,
бэкап и явное восстановление сохранены. Ошибки текущих операций и чтения
профилей по-прежнему показываются. Rust, записи операций, бэкапы и текущие
настройки оформления не менялись.
