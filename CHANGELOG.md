# Changelog

## Unreleased

## 0.8.0 — 2026-11-16

- Удалена поддержка Telegram/Kotatogram: генерация, GUI/CLI, действия и ресурсы
  всех восьми тем. Старые пакеты и apply-journal больше не меняют эти клиенты;
  личные настройки и данные сохраняются.
- Перезапуск после Apply допустим и отмечается отдельно; в конец приоритетов
  попадают ручной выбор/импорт/сброс темы и дополнительная настройка.

- Очередь приложений теперь отдаёт приоритет автоматическому Apply и возврату:
  ручной выбор/настройка и неподтверждённое применение вынесены в P4.
  Автоматический Chromium через BrowserThemeColor отложен после native-проверки:
  снятие политики теряет GTK/Qt baseline; этот путь не включён в Apply.

- Акцент с обоев (`accentColorFromWallpaper`) теперь применяется в темах `glass`
  и `material-you`: в `theme.json` `values.accent_from_wallpaper` переведено в
  `true` (было `false` и перебивало `true` из `kdeglobals` при Apply), убран
  конфликтующий дубль `AccentColorFromWallpaper=false` в `.config/kdeglobals` обеих
  тем. Остальные темы (`dracula`, `everforest`, `frutiger-aero`,
  `frutiger-aero-light`, `minecraft-overworld-dark`, `Paper`) остаются на `false`.
- Maintenance refresh сохраняет пользовательские BreezeLight/BreezeDark и акцент
  от обоев Glass/Material You, убирает конфликтующие варианты регистра ключа.
- Цветовая схема `glass` и `material-you` заменена на `materialbright` (были
  `KoliraGlass`/`KoliraMaterialYou`, потом `BreezeDark`). Файл
  `.local/share/color-schemes/materialbright.colors` добавлен в обе темы из
  пользовательской схемы `BreathDark1.colors` (акцент `0,137,123`, sélection
  `141,74,114`, фон окна `26,17,25`).
- Убраны дублирующие ключи `AccentColorFromWallpaper=false` из `kdeglobals`
  остальных шести тем (`Paper`, `dracula`, `everforest`, `frutiger-aero`,
  `frutiger-aero-light`, `minecraft-overworld-dark`); оставлен только
  читаемый Rust `accentColorFromWallpaper=false`.
- Добавлены цвета из палитры и безопасный возврат для Micro, lsd/Glow,
  GIMP 3, Heroic, Prism, Vim, mpv/Cliamp и VSCodium; все восемь комплектных
  тем обновлены. Chromium/Chrome получают только нативный frame accent с
  ручной загрузкой/reload/сбросом в браузере. LibreOffice исключён пользователем.
- Вложенный отсутствующий ключ JSONC вставляется по позиции существующего
  объекта с сохранением комментариев и личного форматирования.

- Исправлены красные GTK/Breeze colours в Everforest и stale palette resources
  остальных комплектных тем; KDE accent/colour fields, Alacritty/Ghostty и OMP
  теперь обновляются из палитры вместе с прочими поддерживаемыми приложениями.
- Браузеры используют native accent + day/night без переписывания toolbar,
  кнопок, надписей или иконок через CSS. Личный CSS не включается. Добавлены
  проверки фактического акцента/режима Firefox и Zen для всех восьми тем.

- Added the next ten P0 application rows: fish/Pure/Oh My Posh, btop/Cava,
  Yazi/bat, Wofi, fzf, lazygit, Zellij, OpenCode V2, Claude Code and Codex.
  Native appearance fields preserve personal configuration and return to baseline
  when switching to a theme without those fields; AI secrets are excluded.
- Updated all eight bundled themes with the new colour resources and selectors.
  bat cache rebuild now participates in rollback and return-to-baseline recovery.


- Замена объектов/массивов в JSONC выполняется на месте: повторное обновление
  editor overrides, Zed theme и Obsidian snippet list не создаёт дубли ключей;
  окружающие комментарии и личные значения сохраняются.

- Все восемь комплектных тем обновлены для первых десяти групп приложений:
  палитры, встроенные темы Cursor/VS Code с цветами, собственные Zed/Neovim,
  безопасные browser colours/day-night и ресурсы мессенджеров/терминалов.
  Material You добавлен как публичный пакет без личных путей и библиотек.
- Исправлен экспорт browser colours из снимка с другим именем default profile;
  ресурсы и day/night больше не теряются при переносе ZIP.

- Первая партия покрытия приложений: Cursor/Zed, Neovim, Obsidian,
  Zen/Firefox/Pywalfox, Discord/Vesktop, Kitty и Konsole/Yakuake.
  Новые ресурсы и ключи выбора включены в preview, rollback и возврат к теме
  без конфига. Личные настройки и поздние изменения сохраняются.
- Neovim получает автономную colorscheme из данных палитры без изменения init
  и установки плагинов; Obsidian — выбор vault и переносимые слоты снимка.
- Zen/Firefox меняют только цвета и day/night; проверяется контраст иконок,
  игнорируются UI CSS/прозрачность старых тем, prefs.js не редактируется.
- Кэш Cursor регистрируется как отдельное расширение только с цветовыми темами;
  повторный save/apply стабилен. Выбор тем Cursor/Zed применяется вместе с кэшем.
- Pywalfox включается явно и требует исходный colors.json. Для открытых Konsole/Yakuake
  предлагается ручное обновление цвета вместо подмены целого профиля.

- Возврат к теме без части конфигов восстанавливает исходное оформление этих
  приложений вместо сброса к defaults. Журнал охватывает INI/JSONC, второй этап,
  удаления, ссылки и права; поздние личные значения и комментарии сохраняются.
- Созданные темой include/prompt-файлы возвращаются вместе с host-конфигом;
  файлы с сохранившимися личными ссылками не удаляются. Пустые пользовательские
  каталоги и поздние изменения размера шрифта/прав сохраняются.
- Обои отсутствующей в теме картинки возвращаются к baseline; явный
  --keep-wallpaper сохраняет текущее изображение и файл. GTK/KWin/Qt
  перезагружают восстановленное состояние без сброса отсутствующего конфига.


- Старые прерванные применения больше не вызывают всплывающую ошибку при каждом
  запуске GUI; запись, бэкап и восстановление остаются в истории смен тем.

- Темы хранят кэш расширений редакторов в `assets/editor-themes/` и переносят
  его через обычный ZIP-экспорт/импорт. Сохранение копирует установленное расширение
  без сети; недостающий кэш загружается только с явным `--install-missing`.
- Двухэтапный Apply: восстановление снимка и затем оформление приложений без
  повторного перезапуска Plasma. Оба этапа включены в preview, общую блокировку,
  бэкап и восстановление. `--without-sync` пропускает генерацию тем приложений и
  установку редакторского кэша; сохранённые настройки приложений восстанавливаются.
  В GUI эта галочка находится в предварительном просмотре применения.
- Расширения устанавливаются целиком в отдельный каталог, VSCodium использует
  `.vscode-oss`; исходные расширения сохраняются. Из устанавливаемого манифеста
  исключаются исполняемые точки входа и вклады, не относящиеся к темам.
- Генерация из палитры требует явного `app_targets[]` (по умолчанию пуст)
  и сохраняет явные ресурсы приложений из снимка. Firefox
  подключает отдельный CSS, сохраняя пользовательский; небезопасная запись
  Chromium Preferences исключена до реализации поддерживаемого адаптера.
- Палитру можно сохранить как новую тему после применения к KDE. Rust повторно
  проверяет фактические цвета перед сохранением и отклоняет устаревшее состояние.
- Кнопка общих системных настроек работает вместе с отдельными переходами к KCM;
  применение подготовленных GUI-правок больше не получает ошибочный аргумент.
- Восстановлены проверки путей назначения ресурсов и безопасная обработка VSIX;
  исправлены устаревшие контрольные суммы комплектной Minecraft-темы.
- Обновление переводов: `python3 gui/qt-app/tools/update_translations.py`.

- Третья партия P0 № 21–29 плюс VSCodium: Micro, lsd/Glow, Chromium/Chrome
  (ручной выбор/сброс кэшированной темы), GIMP 3, Heroic, Prism, Vim,
  mpv/Cliamp и VSCodium — 35 явных `app_targets`, 51 запись реестра. Все восемь
  комплектных тем содержат нативные palette-ресурсы для обеих партий. Новые
  Rust-модули `third_apps.rs`, `native_appearance.rs`, `structured_appearance.rs`,
  `terminal_apps.rs`, `browser_appearance.rs`, `neovim.rs`, `obsidian.rs` и
  пример `examples/refresh_theme_apps.rs` для обслуживания пакетов тем.
- Новые документы: `docs/APPLICATIONS.md` (контракты оформления приложений,
  vault Obsidian, ограничения браузеров и AI-клиентов), `docs/APP_COVERAGE_PRIORITIES.md`
  (очередь P0–P4), аудиты `docs/audits/2026_11_15_app-coverage-files.md` и
  `docs/audits/2026_11_16_palette-consistency.md`.
- Новые тесты: `rust_core/tests/{first_ten,second_ten,third_ten}.rs`, e2e
  `tests/e2e/{browser-native-accent,browser-colour-contrast,editor-cache-native,
  chromium-policy-native,third-apps-native,third-apps-gtk,third-apps-heroic,
  third-apps-clients}.py`.
- Переводы обновлены и собраны (`kolira_ru.qm`, `py_ru.ts`, `qml_ru.ts`).
- Устаревшие `.zen/.../user.js` и `chrome/*.css` убраны из комплектных тем —
  браузеры меняют только нативный акцент и day/night, `prefs.js` не правится.

## 0.7.0 — 2026-11-12

- В пользовательский каталог тем устанавливаются README.md и AGENTS.md v2
  с рабочими рецептами создания тем для агентов; личные дополнения сохраняются.
- MCP сообщает сбой чтения списка тем и требует previewToken при Apply.
  GUI обновляет список в фоне и сохраняет последнее корректное состояние при ошибке.

- Исправлен `CONFIG NOT FOUND` в oh-my-posh после смены темы: Undo сохраняет
  общий файл prompt, на который ссылается shell.
- Minecraft: размытие Better Blur DX как в Glass, полупрозрачные терминалы,
  окна Kvantum и заголовки Klassy.

- Исправлено переключение KDE шрифтов между темами: активный шрифт заголовка
  окна теперь тоже управляется темой и не остаётся Monocraft после выхода из Minecraft.
- GTK-темы синхронизируют семейство обычного шрифта с GSettings; отдельный
  пользовательский моноширинный шрифт сохраняется, в том числе при отмене
  старых тем с записью этого шрифта в журнале.
- Minecraft Overworld Dark явно выбирает тёмный стиль панелей `breeze-dark`.
- Minecraft: в «Параметрах системы» и меню снова разные значки. Из иконпака
  убраны `preferences-desktop`/`preferences-system`: KDE подставлял этот
  «верстак» вместо всех `preferences-desktop-*`/`preferences-system-*`, не доходя до Breeze.
  По той же причине убран `games`, а «сундук» `folder` получил свои варианты:
  открытая папка, документы, загрузки, музыка, изображения, видео, домашняя
  папка и рабочий стол.
- Minecraft: `[Colors:Selection]` получил тёмные вторичные цвета вместо почти
  зелёных на зелёном (у стандартного Breeze так же низко, видимой поломки
  не подтверждено).
- Minecraft: в kitty, Alacritty и Konsole автоподсказки fish больше не сливаются
  с фоном — bright black `#808080` вместо `#404040`.
- Установщик больше не считает комплектную тему «изменённой пользователем»
  после `kolira import … --force`: копия, совпадающая с комплектом, дальше
  обновляется сама. В `theme.json` Minecraft добавлено `optional: false`
  (каноничная форма после импорта).
- Новая команда `kolira lint NAME [--json]`: значки иконпака, перекрывающие
  значки Breeze, нечитаемый текст цветовой схемы и bright black терминалов.
  Текстовый `kolira check` печатает эти предупреждения, `agent.prepare`/MCP
  `prepare_theme` возвращают их в `warnings`; `check --json` не изменился.
- Инструкции агенту для создания тем предупреждают о перекрытии значков Breeze
  и о контрасте цветов выделения; `kolira --help` перечисляет
  `apply --without-dependencies` и `bundled sync`.

- Ошибка или прерывание применения темы больше не создаёт вечную блокировку:
  новые операции доступны после завершения процесса. История ошибок, бэкапы и
  ручное восстановление сохраняются; одновременно выполняющиеся изменения исключены.

- Minecraft Overworld Dark: рабочие Kvantum/GTK, пиксельные иконки, Zed, btop,
  Konsole, yazi и wofi; согласованные метаданные, оригинальные voxel-обои,
  перенос ресурсов при экспорте. Rust поддерживает встроенные темы иконок
  с проверкой путей и симлинков.

- Исправлена ложная ошибка запуска Plasma, блокировавшая удаление и изменение тем,
  когда оболочка работает вне службы systemd: добавлена проверка ответа по D-Bus.

- Kolira: раздельные команды `kolira` (CLI) и `kolira-gui` (GUI), исправленные
  сборка/иконка/комплектные ресурсы, миграция старых каталогов и чтение прежних
  форматов тем/экспортов. Подробности: `docs/RENAMING.md`.

- GUI: единые отступы диалогов/страниц и каналы скроллбаров; перенос действий
  при узком окне/крупном шрифте, полный выбор темы приложения и длинный текст.
- GUI: актуальные значения после «Открыть», видимые ошибки дочерних страниц и
  редактора приложения, фокус карточек и клавиатурная палитра (Tab/Shift+Tab,
  Enter и Space для цветов и акцента). Сводки профилей
  загружаются одним фоновым Rust-запросом.
- Перевод: известные статусы приложений/зависимостей, история и расписание,
  множественные формы, даты/размеры по локали и названия компонентов.

- Расписание тем в локальной Plasma-сессии: правила времени/дней, фоновый Rust
  исполнитель, XDG autostart, результаты и защита от повторов/параллельного apply.
- История 10 завершённых смен с источником, отчётом и проверкой бэкапов;
  восстановление завершённой смены создаёт новую страховочную транзакцию.
- Offline-подготовка темы через MCP `prepare_theme` / Rust `agent.prepare`,
  обнаружение возможностей/схемы, управляемые инструкции в каталоге тем и
  запуск установленного MCP независимо от cwd.
- MCP получает асинхронный запуск, статус и безопасную отмену Rust jobs зависимостей.
- Импорт тем не принимает управляющие файлы агентов и не заменяет корневые
  инструкции; экспорт исключает их из ресурсов.

- Перед ручным Apply в GUI и трее добавлен просмотр файловых изменений,
  сбросов, зависимостей и перезапусков. Можно сохранить текущее оформление
  и оставить обои; устаревший просмотр требует нового подтверждения.
  Добавлены CLI `preview` / `--preview-token` и MCP `preview_profile`.
- Исправлено сохранение текущих обоев при Apply старых снимков; файловые
  преобразования KWin/Konsole и прогноз используют общие Rust-функции,
  Konsole учитывает XDG_CONFIG_HOME. Перезапуски приложений учитывают
  фактические изменения, включая восстановление предыдущей темы.

- В Paper исправлена внутренняя светлая рамка на кнопках: hover использует
  штатное затемнение Sandstone, а рамка фокуса показывается при клавиатурной
  навигации. Другие режимы оформления сохраняют стандартное поведение Qt.

- Защищено применение темы: единая блокировка GUI/CLI/Inspector, предварительная
  проверка и копия исходной темы, автоматический откат файлов при ошибке записи
  или обязательного внешнего шага. Неуспешный Apply возвращает ошибку с ID операции,
  путём бэкапа и отдельным результатом восстановления.
- Добавлены `kolira operations list|show|recover` и обнаружение прерванных
  операций в GUI. Обычное восстановление сохраняет последующие личные изменения;
  принудительная замена доступна явно через `--force`. Бэкапы остаются доступными.

- Завершён перенос оставшейся бизнес-логики в Rust: Inspector и Undo/Revert,
  темы приложений, клонирование KDE/Kvantum, настройки, реестры и обои.
  GUI остаётся Python/PySide6 + QML; общий JSON API обслуживает GUI и MCP.
- Настройки сохраняют неизвестные ключи и политики automation, параллельные
  запросы сериализуются; сессии/бэкапы приватны, запись сохраняет права файлов.
  TOML сохраняет типы и комментарии; ошибки Apply/Undo доступны для повтора.
  MCP возвращает `isError:true` при неуспехе операции.

- Исправлены 11 дефектов аудита: ограничены назначения ресурсов темы и ссылки
  при восстановлении, сохранены неудачные staged-правки и корректный результат
  частичного Apply, MCP проверяет запросы/имя до изменений и продолжает работу
  после некорректного запроса, bat ограничен таймаутом с диагностикой.
- Исправлены обновление открытой страницы компонентов, выбор папки обоев,
  состояние ошибки предпросмотра, гонка поиска палитр, рост объектов фоновых
  задач и исчезновение таблицы зависимостей из-за длинного журнала.
- Удалены неиспользуемые внутренние функции и импорты; offscreen Python-тесты
  стали обязательными в CI, добавлены проверки CLI/установщика и shellcheck.

- Добавлена страница «Зависимости»: галочки выбора, отдельные столбцы названия
  и категории, установка, удаление выбранных и переустановка с проверкой состояния
  и предупреждением о затронутых темах.
- Единый реестр Rust учитывает зависимости приложения и тем, происхождение и
  владение ресурсами. Старый реестр мигрируется с резервной копией; внешние и
  изменённые файлы защищены от удаления.
- Установка показывает прогресс и поддерживает отмену текущей загрузки.
  Ошибки не приводят к автоматическому применению темы; добавлены явное применение
  без зависимостей и «Больше не спрашивать» для магазинов и пакетов.

- Темы больше не меняют fastfetch и меню запуска Plasma, включая значок кнопки. Старые темы и журнал отката также оставляют fastfetch без изменений. Simple Application Launcher не требуется.
